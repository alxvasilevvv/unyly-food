# Unyly for Grab

Сервисы Grab через ИИ-ассистентов: удалённый MCP-сервер + веб-кабинет с обязательным подтверждением каждого заказа человеком. Один сценарий для всего: еда, магазины (продукты, магазин у дома, цветы, аптека, торты), поездки и посылки.

> **Статус (30.09.2026).** Сервис **опубликован**: https://unyly-food.unyly.org (MCP: `https://unyly-food.unyly.org/mcp`). Хостинг: Unyly Deploy, база: Supabase (схема `unyly`). Demo работает полностью для всех четырёх сервисов (данные только по Бангкоку). Handoff работает для всех сервисов и всех 8 рынков Grab: ссылки Таиланда проверены, остальные ведут на `grab.com/{cc}/` и помечены как непроверенные. **Live-заказы Grab недоступны**: публичного API, через который третья сторона заказывает еду, товары или поездку от имени покупателя, у Grab нет ([docs/feasibility.md](docs/feasibility.md)). Мульти-сервисная версия на живом сервере повторно не проверялась.

## Сервисы

| Сервис | Что в Demo | Инструменты |
|---|---|---|
| `food` | 6 вымышленных ресторанов Бангкока, модификаторы, аллергены, промо | `search_stores`, `get_store` |
| `mart` | супермаркет, магазин у дома, цветы (обёртка обязательна, текст открытки в `note`), аптека (только безрецептурные средства домашней аптечки, лимит `max_quantity` на заказ), торты (надпись в `note`) | `search_stores`, `get_store` |
| `ride` | 6 типов машин (GrabBike ... GrabVan), тариф по формуле «посадка + км + минуты», сбор 50 THB за посадку в аэропорту | `estimate_trip` |
| `express` | посылки: Bike до 20 кг, Car до 100 кг, SUV до 200 кг, Pickup до 300 кг | `estimate_trip` |

Дальше путь общий: `create_cart` → `quote_cart` → `prepare_checkout` → человек подтверждает на странице Unyly → `submit_order` → `get_order_status`. Места для поездок и посылок задаются словами на EN, RU или TH: ориентиры, районы или названия сохранённых адресов. На просьбу «в аэропорт» сервер спрашивает, какой из двух.

## Витрина для Grab

- `/` - лендинг концепта «Unyly for Grab» с сеткой сервисов (EN, TH, RU; переключатель языка в шапке).
- `/try` - интерактивное демо без регистрации для всех сервисов: запрос обычными словами на любом из трёх языков («ужин на двоих», «розы с открыткой», «такси от Siam Paragon до аэропорта», «посылка 3 кг») → варианты с ценой со всеми сборами → страница подтверждения → живой статус. Создаётся гостевой аккаунт, он удаляется через 24 часа; гостевые заказы проходят путь за ~3 минуты (`DEMO_GUEST_SPEED`).
- `/connect` - как подключить 10 популярных ассистентов, с честным статусом для каждого.
- `/for-grab` - предложение о партнёрстве: архитектура, что уже сделано, защита, что нужно от Grab, пилот.

На каждой странице есть полоса «концепт, не связан с Grab». Логотипы и фирменный стиль Grab не используются: только название для описания интеграции, собственная зелёная палитра и оригинальные иллюстрации.

## Быстрый старт (локально)

Нужны Node.js ≥ 22 (рекомендуется 24 LTS) и PostgreSQL ≥ 15.

```bash
npm ci
createdb unyly && createdb unyly_test         # или: docker compose up -d db
cp .env.example .env
# для локальной разработки в .env достаточно:
#   NODE_ENV=development
#   DATABASE_URL=postgres://postgres@localhost:5432/unyly
#   WEB_ORIGIN=http://localhost:3000
#   MCP_RESOURCE_URL=http://localhost:3000/mcp
#   MAIL_MODE=console
#   DEV_ECHO_LOGIN_CODE=true
#   DEMO_TIME_SCALE=20   # демо-доставка в 20 раз быстрее
npm run dev
```

Откройте http://localhost:3000 → «Войти»: создайте аккаунт с passkey или войдите по коду (в dev-режиме код показывается прямо на странице) → «Регион и режим» → «Адреса» → «Подключение».

Вариант целиком в Docker: `docker compose up --build db app` (без TLS, порт 3000).

### Проверить весь путь одной командой
```bash
BASE_URL=http://localhost:3000 npm run e2e:mcp
```
Скрипт проходит OAuth-discovery, регистрацию клиента, PKCE и весь сценарий через MCP, подтверждает заказ как человек на странице и печатает Bearer-токен для MCP Inspector. **Внимание:** `scripts/mcp-e2e.ts` ещё не обновлён после переименования инструментов (`search_stores`, `store_id`) и сейчас останавливается на шаге поиска.
```bash
npx @modelcontextprotocol/inspector --cli http://localhost:3000/mcp --transport http \
  --header "Authorization: Bearer <token>" --method tools/list
```
`E2E_STOP_BEFORE_CONFIRM=1` останавливает скрипт перед подтверждением и печатает ссылку, чтобы подтвердить заказ руками в браузере.

### Подключить ассистента
- Claude Code: `claude mcp add --transport http unyly http://localhost:3000/mcp`, затем `/mcp`.
- Остальные клиенты: [docs/clients.md](docs/clients.md) (им нужен публичный https-адрес).
- Клиенты без OAuth: персональный токен `unyly_pat_…` из «Подключений» (`/app/connections`), только в заголовке `Authorization: Bearer`.

## Проверки, выполненные при сдаче
- `npm test`: 10 файлов, 103 теста, все прошли (после мульти-сервиса; включая регрессионные тесты по итогам ревью). `npm run typecheck` - без ошибок.
- `npm run e2e:mcp` на локальном сервере после мульти-сервиса (30.09.2026) - пройден; до мульти-сервиса также на живом сервере; MCP Inspector 2.8.0 CLI - `tools/list`, `tools/call` работают.
- Мобильный путь в Chromium 390×844 без горизонтальной прокрутки и ошибок консоли; клавиатурная навигация.
- Production-сборка стартует, `/readyz` = ready; `caddy validate` - ok; бэкап и восстановление - ok.
- Не выполнено: `docker build` (нет Docker daemon в среде; шаг есть в CI), ручное подключение ассистентов со страницы `/connect`.
