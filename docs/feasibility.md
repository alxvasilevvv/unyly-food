# Отчёт о реализуемости интеграции с Grab

Дата проверки: **30.09.2026**. Все выводы ниже опираются только на официальные источники. Если документацию не удалось открыть, пункт помечен как «не проверено».

## Вывод

1. **Live-заказы GrabFood от имени покупателя сейчас нереализуемы.** Grab не публикует API, через который третья сторона могла бы искать рестораны, рассчитывать корзину, оформлять и оплачивать заказ за покупателя. Публичный GrabFood API устроен для ресторанов и POS-систем: ресторан синхронизирует своё меню и получает свои заказы.
2. **Авторизация от имени пользователя Grab (GrabID / Login with Grab) существует, но scopes выдаются только при ручном онбординге партнёра.** Публично описан один scope, `openid`. Scope для заказа еды не документирован.
3. **Пользовательские условия Grab запрещают ботов, скрипты и скрейпинг.** Поэтому автоматизация приложения, cookies и приватные API исключены.
4. **Доступный сейчас путь - Handoff.** Это официальная веб-точка входа GrabFood Таиланда без параметров корзины и ресторана, плюс Demo для полного сценария.
5. **Отдельное направление расширения - GrabExpress Delivery API.** Он документирован, есть sandbox. Но это курьерская доставка посылок для бизнеса, а не заказ еды из ресторана.

**Страна запуска:** Таиланд. Это **предварительное продуктовое допущение**, а не результат проверки доступа: реального доступа к Grab нет ни в одной стране. Выбор опирается на два факта: GrabFood работает в TH (GrabFood POS API, раздел Available regions), а у THB exponent = 2 (там же, раздел о валютах).

## MCP и клиенты (кратко, подробности в `clients.md`)

- Последняя версия спецификации MCP - **2026-07-28**: stateless-протокол, без `initialize` и `Mcp-Session-Id`. Официальные TypeScript SDK (`@modelcontextprotocol/sdk` 1.31.0 от 28.09.2026 и `@modelcontextprotocol/server` 2.2.0) реализуют протокол до **2025-11-25** включительно.
- Выбор: SDK 1.31 + Streamable HTTP в stateless-режиме. Состояние корзины хранится в серверных идентификаторах (`cart_id`, `checkout_id`), как и рекомендует 2026-07-28. Поэтому переход на новую ревизию сводится к обновлению SDK.
- Авторизация: OAuth 2.1 + PKCE S256, RFC 9728 (Protected Resource Metadata), RFC 8707 (`resource` и проверка audience), RFC 8414, Client ID Metadata Documents (SHOULD) и Dynamic Client Registration (MAY, deprecated, оставлена для совместимости).

## Что это значит для продукта

| Режим | Статус | Что делает |
|---|---|---|
| Demo | **Работает** | Полный сценарий на синтетических данных, без списаний |
| Handoff | **Работает** | Список блюд и официальная ссылка GrabFood TH. Заказ, оплата и статус - внутри Grab |
| Live | **Выключен** | Все возможности возвращают `CAPABILITY_UNAVAILABLE` с причиной и источником |

Черновик обращения к Grab лежит в `grab-partner-request.md`. Он не отправлялся.
